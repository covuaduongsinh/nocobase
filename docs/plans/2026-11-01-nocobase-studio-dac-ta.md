## 0. Kết luận quan trọng nhất (đọc trước)

1. **NocoBase Studio không phải "bộ plugin nâng cao" của NocoBase 2.** Nó là một **ứng dụng NocoBase 3** riêng
   (`@nocobase/studio`, demo đang chạy bản `1.0.0-beta.71`), đóng vai trò **nền tảng quản trị để con người và các
   coding agent (Claude Code, Codex, OpenCode, Gemini CLI, Cursor…) cùng phát triển phần mềm**: tiếp nhận yêu cầu →
   lead agent phân công → agent thực thi trên runtime (máy chạy) → CI/review → người nghiệm thu → phát hành.
2. **Phần lõi của Studio là mã nguồn mở**, nằm trên nhánh `v3-develop` của `nocobase/nocobase` (đã fetch về máy là
   `upstream/v3-develop`, commit `04922adec1`, 31/10/2026): các plugin `app-plugin-agents`, `app-plugin-projects`,
   `app-plugin-releases`, `app-plugin-knowledge`, `app-plugin-agent-sessions`, gói `agent-runner`, `agent-protocol`,
   `acp-bridge`, `app-cli-client`, `app-host`, `app-host-docker`, và template ứng dụng NocoBase 3.
3. **Phần "Studio" đóng (thương mại)** là lớp lắp ráp mỏng hơn nhiều: ứng dụng `@nocobase/studio` (từng được import vào
   `packages/apps/studio` ở PR #10666 ngày 10/10/2026, rồi **chuyển về repo riêng** ở PR #10936) gồm: kết nối Git
   (GitHub App / GitLab / Gitee), theo dõi PR/checks/preview/version, "project manager" (lead agent) và các skill
   `studio-*`, trang Dashboard, Follow-ups, Project memory, Testing (quality), Inbox hợp nhất, vai trò tuỳ biến, CLI
   thương hiệu `nb-studio`, cài đặt qua ảnh Docker private `pkg-v3.nocobase.com/nocobase/studio`.
4. Studio chỉ bán kèm **Professional (8.000 USD, vĩnh viễn, 1 năm nâng cấp) hoặc Enterprise**; không bán lẻ. Core và
   Solution miễn phí. Mọi thứ tự host.
5. Vì vậy, "có đầy đủ tính năng Studio" đồng nghĩa với **lắp một ứng dụng NocoBase 3 từ các plugin mở + tự viết lớp
   Studio** (xem kế hoạch), **không phải** cài thêm plugin vào NocoBase 2.2.36 đang chạy ở Dương Sinh.

## 3. Vòng đời một yêu cầu (8 bước, docs `how-a-request-gets-done`)

1. **Request** — owner trò chuyện trong My sessions; agent kiểm tra module hiện có, chốt rule → tạo issue (Backlog) → owner bấm **Start** (In progress).
2. **Assign** — lead agent giao bước đầu (design nếu phức tạp, rồi develop) theo "Good at"; mỗi handoff ghi vào comment: agent, mục tiêu, tham chiếu, tiêu chí hoàn thành, lý do.
3. **Clarify** — câu hỏi nghiệp vụ → issue **Blocked** + "Needs you"; owner trả lời ở My issues → tiếp tục.
4. **Develop** — agent chạy trên runtime, commit vào nhánh task, mở PR gắn issue.
5. **Check & review** — CI chạy checks; fail → quay lại dev; **review chéo nhà cung cấp** (model không review code của chính nó); findings có mức độ, nêu rõ blocker.
6. **Accept** — lead agent viết **delivery report** (Before / Agreed approach / What changed / How it was checked / Open issues / Details / Acceptance criteria + ảnh chụp) → **In review**; owner xem preview, bấm **Merge** (hoặc Send back) → **Done** khi mọi PR merge.
7. **Release** — CI deploy test env; project lead gom vào version (tag); đội tự deploy production; Studio ghi version và đánh dấu issue "in test / in production / withdrawn".
8. **Remember** — agent ghi project memory, review cùng PR.

Quy tắc đáng nhớ: chỉ **người** mới accept/merge/approve deploy/quản lý thành viên & key; **3 commit liên tiếp fail** → ngừng đánh thức agent, báo owner; **Merge anyway** cần lý do và được ghi log; `/note` trong comment không đánh thức agent; mention agent chỉ trả lời, không đổi trạng thái.

## 9. CLI & giao thức

- **`nb-studio`** (= `@nocobase/studio-cli`, build từ `@nocobase/app-cli-client`): không có lệnh cứng; sau `login --server <url>` (trình duyệt hoặc `--api-key-stdin`), CLI tải **manifest lệnh** từ `GET /api/cli/manifest` theo quyền người dùng. Nhóm lệnh: `issue, comment, attachment, project, label, project-manager, agent, runtime, skill, variable, run, report, kb, memory, git, pr, commit, preview, app, deploy, env, release, build, registry, inbox, follow-up, session, conversation, user, access, api-key`; lệnh tĩnh: `whoami [--missing]`, `skills install|status`, `docs`, `update`, `logout`, `profile list|use`, `acp start|service install|status|uninstall`. CI dùng `NB_STUDIO_SERVER` + `NB_STUDIO_API_KEY`. Cài bằng `curl … | sh -s -- --token <download credential 30 phút>` (Node 24+).
- **`nocobase-runner`** (`@nocobase/agent-runner`, Apache‑2.0): `register` (token một lần), `start`, `status`, `logs`, `stop`, `service install|uninstall` (launchd/systemd user), `env set|unset|list`, `update`, `gc`, `config set min-free-disk|agent-tools|artifact-ttl|artifact-patterns`, `config models <tool> add|remove|reset|show`, `uninstall`, `unregister`. Thư mục `~/.nocobase-runner/` (policy.json, apps/<key>.json) và `~/.nocobase-runner-work/<app>/<subject>.task/`.
- **Giao thức** `@nocobase/agent-protocol` phiên bản 12 (min 3): register → heartbeat → claim (`?wait=true`, 25 s) → lease/start → events (batch idempotent theo `(runId, seq)`) → complete/fail/cancelAck; `RunPayload` không chứa khái niệm nghiệp vụ (app, subject, tool+model+effort+policy, prompt với `{{runner.workspaceNotes}}`, workspace dirs repo/directory + env + mounts + git + skills bundle + cli credential); jobs `build`; dist tarball theo target + SHA‑256; quota windows; redaction 2 lớp.
- **ACP bridge** (`@nocobase/acp-bridge`): chạy trên máy cá nhân (macOS/Linux/Windows), đăng ký máy, phát hiện 17 agent (Codex, Claude Code, Gemini CLI, Copilot, Cursor, OpenCode, Qwen Code, Kimi CLI, CodeBuddy, Qoder, Goose, Auggie, Factory Droid, Kilo Code, Cline, Amp, Mistral Vibe), long‑poll lệnh, chạy agent qua Agent Client Protocol, chỉ cần HTTPS outbound; phiên chỉ trong thư mục cho phép; permission chờ ≤30 phút.
